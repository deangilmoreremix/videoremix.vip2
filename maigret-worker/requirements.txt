# NOTE: maigret is intentionally NOT pinned. Public PyPI only publishes maigret
# up to 0.4.4; the 0.5.0/0.6.3 versions historically referenced are not on the
# public index and resolve to a Rust/maturin sdist that fails to build on Render's
# read-only filesystem (and on Python 3.14 there are no prebuilt wheels for
# pydantic-core either). The scanner imports maigret defensively and degrades to
# an empty result when it is unavailable, so the worker still builds and serves
# /health + /scan (with a seed-only graph). To enable real Maigret scans, install
# maigret from its source repo or a private wheel for the target Python.
#
# FastAPI/pydantic are pinned to the v1 stack (pydantic 1.10 is pure-Python, no
# Rust pydantic-core) and uvicorn is used WITHOUT [standard] so no httptools/uvloop
# Rust extensions are required — this builds cleanly on Render's Python 3.14.
